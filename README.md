# Jom Lepak Car Wash (JLCW) Website

Modern static website for **Jom Lepak Car Wash (JLCW)** with a premium black-gold theme.

## Files

- `index.html` - Main page and all required sections
- `styles.css` - Premium responsive styling (mobile-first)
- `script.js` - Mobile menu toggle and smooth UX helpers

## Included Sections

1. Navigation bar with logo placeholder, menu links, WhatsApp button
2. Hero banner with tagline and CTA
3. About section with business highlights and photo placeholder
4. Services section (5 services with placeholders)
5. Membership packages (Blue, Silver, Gold) with pricing and benefits
6. Reviews/testimonials placeholders with star rating structure
7. Location and hours section with embedded Google Map
8. Contact section with large WhatsApp CTA

## Usage

Open `index.html` directly in your browser.

## Customize Later

- Replace logo placeholder in navbar (`.logo-frame`)
- Replace photo placeholders in About/Services sections
- Replace review placeholders in Reviews section
- Adjust colors through CSS variables in `:root` inside `styles.css`
